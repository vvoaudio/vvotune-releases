# TUNE VVO — macOS Universal installer

`TuneVVO-1.0.0-macOS-Universal.pkg` — for **every Mac running macOS 11 Big Sur or later**:
all Apple Silicon Macs (M1, M2, M3, M4 and later) and Intel Macs.

Same plug-in and same sound as the Tahoe installer; use this one if your Mac runs anything older than macOS 26 Tahoe.

Install steps (including the one-time **Open Anyway** step) are in the [main README](../README.md#install-on-mac).

Tested: installed over an existing older copy (including the earlier name, VvoTune) and validated (pluginval at strictness 10 + 56 sound
checks) on macOS 15 Sequoia and macOS 14 Sonoma (Apple Silicon). Built for a minimum of macOS 11.0.
